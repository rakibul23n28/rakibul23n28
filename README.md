### 👨‍💻 About Me
I’m a Full Stack Developer who actually enjoys the "puzzle" part of coding. Whether I’m polishing a UI for a seamless user experience or architecting a robust backend, I love the process of turning a blank editor into a living, breathing application. 

For me, it’s not just about making things work—it’s about writing clean, efficient code that’s easy to live with. I’m a big believer in staying curious, so I’m always poking around new industry trends and looking for better ways to solve complex problems. 

- 🔭 **Current Focus:** Building out some personal full-stack projects to push my limits.
- 🌱 **Leveling Up:** Deep-diving into the React and Node.js ecosystems to master the finer details.
- 💬 **Let's Chat:** Hit me up about anything Web Dev—especially if it involves React, TypeScript, or the magic of SQL/PostgreSQL.
- ⚡ **Fun Fact:** I’ve spent way too many hours debugging a problem only to realize I missed a single semicolon. We’ve all been there, right?
